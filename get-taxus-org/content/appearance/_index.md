### Themes (Nope)

Taxus does not have, nor will ever have, a theming system.

Theming systems are heavy and by necessity overly opinionated. They also bring in added complexity as a common solution is to use version control. This puts you in the position of relying on someone else's work.

### Tailwind (Nope)

Taxus does not use legacy build systems for styles. Enough said.

### Simple SCSS Compilation

Taxus compiles SCSS using [grass](https://github.com/connorskees/grass). Write styles in `styles/` and the build system compiles them to `dist/css/`. You're in charge—write modern CSS with variables, nesting, and mixins.

### Documentation

For complete styling reference, see the [Styling documentation](https://crustyrustacean.github.io/taxus/styling.html).
