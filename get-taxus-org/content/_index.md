## An opinionated static site generator

This is a static site generator project, founded in Tera and leveraging WebAssembly via Yew.

## Features

- fast (it's Rust)
- scalable 
    - static files
    - easily hostable
    - no databases
- opinionated (let's you get started with sane defaults)
- founded in Tera, a battle tested template library
- built in SCSS compiler (thanks to `grass`)
- javascript ready to go for simple things
- WebAssembly (with Yew) for complex or performant things (see below for a WebAssembly counter widget)
